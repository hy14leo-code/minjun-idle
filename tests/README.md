# 테스트 도구

게임(`index.html`)을 헤드리스 브라우저로 검증하는 스크립트입니다. Node.js와 Playwright가 필요합니다.

## 준비: 계측용 사본 만들기
게임 내부 함수를 호출할 수 있도록 `window.__ev` 를 넣은 사본을 만듭니다. 원본은 바뀌지 않습니다.

```bash
python3 tests/mkinst.py index.html /tmp/inst.html
```

## 무작위 조작 테스트 (오류 탐지)
화면의 버튼을 무작위로 눌러 스크립트 오류와 깨진 값(NaN 등)을 찾습니다. 두 번째 인자는 난수 시드입니다.

```bash
node tests/fuzz.js /tmp/inst.html 1
```

`{"bad":[],"n":0,...}` 와 `errs []` 가 나오면 통과입니다.

## 밸런스 시뮬레이션
봇(`bot.js` + v2 콘텐츠용 `bot2.js`)이 게임을 빠르게 진행해 스테이지 도달 시간을 측정합니다. 인자는 시뮬레이션 시간(시간 단위)과 출력 간격입니다. `tests/` 폴더 안에서 실행합니다.

```bash
cd tests && node sim7.js /tmp/inst.html 100 25
```

출력의 `{"20":0.1,"100":2.3,...}` 는 각 스테이지에 처음 도달한 시뮬레이션 시간입니다. 봇은 쉬지 않고 최적에 가깝게 플레이하므로 실제 플레이어보다 빠릅니다. 같은 설정에서도 편차가 크니 여러 번 돌려 중앙값으로 판단하세요.
